================================================================
  Matcap Maker  -  Quick Start Guide / 使い方早見表
================================================================

Matcap Maker は、3Dモデル用 Matcap テクスチャを直感的に作成できるツールです。
複数のレイヤーを重ね合わせて Matcap を組み立てます。

----------------------------------------------------------------
  画面構成
----------------------------------------------------------------
  左   : レイヤーリスト（重ね順・表示/非表示・追加/削除）
  中央 : プレビュー（球体に Matcap をリアルタイム表示）
  右   : 選択中レイヤーのプロパティ

----------------------------------------------------------------
  レイヤーの種類と主な調整項目
----------------------------------------------------------------

[Base Layer]
  色を設定し、ノーマルマップ適用プレビューを制御します。
  - カラー           : ベースカラー
  - モード           : Standard / With Normal Map
  - ノーマルマップ   : 読み込む画像ファイル
  - 強度/スケール    : ノーマルマップの適用量

[Spot Light]
  ハイライトや局所的な光源を追加します。
  - ブレンドモード / 強度 / 範囲 / ぼかし
  - スケール X/Y / 回転 : 光の形状を変形
  - 方向 X/Y/Z     : 光が当たる方向
  - カラー          : 光の色

[Fresnel / Rim]
  輪郭部分にリムライトを追加します。
  - 強度 / パワー（エッジの鋭さ）/ バイアス
  - カラー

[Noise]
  全体にノイズ・テクスチャ感を加えます。
  - 強度 / スケール / シードオフセット
  - カラー（Multiply モードで影に利用可）

[Image]
  任意の画像をテクスチャとして貼り付けます。
  - マッピング : UV / Planar（平面投影）
  - オフセット X/Y / スケール / 回転 / ぼかし / 不透明度

[Color Adjustment]
  それまでの合成結果に色調補正を適用します。
  - 色相 / 彩度 / 明度 / コントラスト

[Gradient]
  球面にカラーグラデーションを重ねます。
  - ブレンドモード / 角度（0〜360°）
  - タイプ : Linear（線形）/ Radial（放射状）
  - グラデーションカラー :
      帯をクリック      → カラーストップを追加（最大8個）
      ピンをドラッグ    → 位置を移動
      ピンをダブルクリック → カラーを直接編集
      削除ボタン        → 選択中のストップを削除（最低2個維持）

----------------------------------------------------------------
  基本操作
----------------------------------------------------------------
  レイヤー追加   : [Add Layer] ボタン → 種類を選択
  表示/非表示    : レイヤー左の丸ボタンをクリック
  並び替え       : ドラッグ＆ドロップ
  複製/削除      : レイヤーを右クリック
  エクスポート   : 画面下「画像をエクスポート」または File > Export Image

----------------------------------------------------------------
  メニュー
----------------------------------------------------------------
  File    : 新規 / 開く / 保存 / エクスポート
  Options : 言語切替 / 解像度 / パディング
  Help    : サードパーティライセンス表示

  ※ 詳細な操作説明は DOCS/使い方.pdf または DOCS/USAGE.pdf を参照。
